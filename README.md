# Marchel Records

Запись всего звука Mac (или одного приложения) в файл — одной кнопкой.

**Скачать:** раздел [Releases](../../releases/latest) → `Marchel-Records.dmg`.

## Установка
1. Откройте `Marchel-Records.dmg`, перетащите **Marchel Records** в «Программы».
2. Первый запуск: приложение без подписи Apple, поэтому macOS его заблокирует.
   Откройте **Системные настройки → Конфиденциальность и безопасность** → внизу «Marchel Records заблокировано» → **Всё равно открыть**.
   (Или в Терминале: `xattr -dr com.apple.quarantine "/Applications/Marchel Records.app"`)
3. При первой записи разрешите доступ в **Запись экрана и системного звука** и перезапустите приложение.

## Возможности
- Запись всей системы или одного приложения (Chrome, Safari, Spotify…)
- Стрелочные VU-индикаторы L/R, счётчик времени
- WAV 24 бит / 48 кГц, M4A (AAC 256), ALAC без потерь
- Автообрезка тишины в начале и конце
- Глобальная горячая клавиша ⌥⌘R из любого приложения, пробел в окне
- Значок в строке меню
- Журнал записей: прослушать, показать в Finder, перетащить в Resolve
- Выбор папки (по умолчанию — Рабочий стол)

Требуется macOS 13 Ventura или новее.
